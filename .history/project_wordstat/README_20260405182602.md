# Проект по автоматизации подбора ключевых фраз и проверки их в Wordstat

Данный проект представляет собой вспомогательный инструмент для автоматизации работы с ключевыми фразами информационных статей. Его основная задача — сократить объем ручной работы при подборе ключевых запросов и их проверке в сервисе статистики поисковых запросов Яндекс Wordstat.

В обычном рабочем процессе специалист сначала парсит сайт, например с помощью Screaming Frog, и получает список страниц с заголовками и мета-данными. Далее вручную отбираются информационные статьи, и для каждой страницы формулируется ключевая фраза. После этого каждую фразу необходимо отдельно проверить в Wordstat, чтобы узнать ее частотность.

Этот процесс трудоемкий и занимает значительное количество времени. Разработанный инструмент решает сразу несколько задач:

- автоматически очищает и нормализует данные, полученные после парсинга сайта;
- автоматически определяет вероятные ключевые фразы на основе заголовков страниц;
- отсеивает страницы, которые не относятся к информационным статьям;
- автоматически отправляет ключевые фразы в Wordstat и получает их частотность;
- формирует единый итоговый файл со всеми результатами.

Важно отметить, что полностью автоматическое и идеальное определение ключевой фразы по универсальным правилам практически невозможно. Структура сайтов, формулировки заголовков и смысл страниц сильно различаются. Поэтому разработанный сервис не заменяет специалиста, а выступает вспомогательным инструментом, который ускоряет работу и уменьшает объем ручных операций.

В результате пользователь получает автоматически сформированный список ключевых фраз, который можно проверить и при необходимости скорректировать.

## Результат работы программы

На выходе система формирует единый Excel-файл, содержащий обработанные данные.

В нем представлены следующие основные столбцы:

### URL
Адрес страницы, с которой была извлечена информация. Позволяет быстро перейти к исходной статье и проверить корректность выбранного ключа.

### Title
Заголовок страницы (`meta title`), полученный при парсинге сайта.

### H1
Основной заголовок статьи (`H1`), который часто наиболее точно отражает тему страницы и используется для генерации ключевой фразы.

### keyphrase
Автоматически определенная ключевая фраза. Обычно она формируется из `H1` или `Title` и очищается от лишних элементов: служебных слов, пунктуации, хвостов после точки или тире.

### query_api
Фраза, которая отправляется в API Wordstat для проверки частотности. В большинстве случаев она совпадает с ключевой фразой.

### totalCount
Частотность запроса в Яндекс Wordstat. Этот показатель позволяет оценить, насколько часто пользователи ищут данную тему.

### status
Текущий статус обработки ключа.

Возможные значения:
- `pending` — ключ еще не отправлялся в Wordstat;
- `done` — частотность уже получена.

## Практическая ценность

Использование инструмента позволяет:

- существенно ускорить процесс подготовки ключевых фраз;
- снизить количество ручных действий при работе с Wordstat;
- систематизировать результаты в одном файле;
- постепенно накапливать и обновлять данные по ключевым запросам.

Таким образом, разработанный сервис выполняет роль интеллектуального помощника специалиста по SEO-аналитике: он автоматизирует рутинные операции, но оставляет человеку финальный контроль над выбором ключевых фраз.
